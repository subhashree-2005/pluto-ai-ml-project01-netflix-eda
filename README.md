**Author:** Subhashree Aich

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies & TV Shows dataset to uncover patterns, trends, and business insights.

## Tools Used
- Python
- Pandas (data manipulation)
- NumPy (numerical computing)
- Matplotlib & Seaborn (visualization)
- Google Colab

## Dataset
- Source: [Kaggle - Netflix Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- Total records: 8,807 shows and movies

## What This Project Contains
1. Data loading and inspection
2. Data cleaning (handled missing values, removed duplicates)
3. EDA with 5 key questions answered
4. 6+ visualizations (bar chart, line chart, histogram, scatter plot)
5. 5 business insights with recommendations

## Key Findings
- Movies dominate Netflix content (more than TV shows)
- United States produces the most content
- Content production has increased dramatically since 2010
- Average movie duration is ~100 minutes
